Use restack inside AI agents

restack ships a built-in Model Context Protocol (MCP) server: restack mcp. Point Google Antigravity, Hermes Agent, Claude Code, Cursor or Windsurf at it and drive a full legacy→modern migration conversationally — no shell required.

What the agent gets

ToolWhat it doesAPI key
restack_scanStack detection, file inventory, token & cost estimatenot needed
restack_planStructured migration plan (dry run) — mappings, routes, waves, risksneeded
restack_convertFull conversion with verify/repair, checkpoint & resumeneeded
restack_statusInspect a previous run: per-file statuses, spend, what would resumenot needed

Every tool result carries an agent-facing summary plus a machine-readable _restack JSON block, so the agent can chain scan → plan → convert → status and react to real data (cost, waves, failures) instead of parsing prose.

Prerequisites (both platforms)

  1. Node ≥ 20 — check with node -v.
  2. restack on PATH (recommended): 
    npm install -g restack-ai
    The npx -y restack-ai form also works everywhere, but the first run downloads the package and is slower.
  3. One provider key for plan/convert: ANTHROPIC_API_KEY, OPENAI_API_KEY/OPENROUTER_API_KEY or GEMINI_API_KEY (see CLI Reference → Providers).
  4. Sanity check in a normal terminal first: 
    restack scan ./legacy-app   # should print the stack summary
restack mcp                 # starts and waits silently — that is correct
    restack mcp is a stdio server, not a REPL: it speaks JSON-RPC on stdin/stdout and logs to stderr. Silence is success — kill it with Ctrl+C.

Google Antigravity

Antigravity 2.0, the Antigravity IDE and the Antigravity CLI all read the same mcpServers JSON shape (see the official MCP docs).

  1. Open the MCP config editor.
    • Antigravity 2.0: Settings (bottom-left) → Customizations → Installed MCP Servers → Add MCP (this opens the MCP Store — restack is not in the store, so continue below) → close the store and open View raw config.
    • Antigravity IDE: … at the top of the agent side panel → MCP Servers → Manage MCP Servers → View raw config.
    • Antigravity CLI: type /mcp in the prompt panel for the interactive manager, or just edit the file directly.
    The file lives globally at ~/.gemini/config/mcp_config.json, or per-workspace at .agents/mcp_config.json in your project.
  2. Add the restack server (merge into the existing mcpServers object): 
    {
  "mcpServers": {
    "restack": {
      "command": "restack",
      "args": ["mcp"],
      "env": {
        "ANTHROPIC_API_KEY": "sk-ant-..."
      }
    }
  }
}
    Windows / no global install? Use the npx form, which needs no PATH setup: "command": "npx", "args": ["-y", "restack-ai", "mcp"].
  3. Save and refresh the server list (the refresh button in Customizations, or the agent panel's MCP Servers view). A green/active status ring means the handshake succeeded.
  4. Verify — in the agent panel ask: “Use restack_scan on ./legacy-app and tell me the stack, confidence and estimated conversion cost.” The agent should call the tool and quote real numbers.
Cost tip: restack_convert spends real money. Antigravity supports "disabledTools": ["restack_convert"] on the server entry — the agent can still scan and plan, while conversions stay behind an explicit request you re-enable when ready.

Hermes Agent

Hermes uses a YAML config with a mcp_servers: mapping (see the MCP config reference). You can also add servers through the desktop Profile Builder dashboard.

  1. Install restack — npm install -g restack-ai (Node ≥ 20).
  2. Edit your Hermes config (typically ~/.hermes/config.yaml) and add the server: 
    mcp_servers:
  restack:
    command: "npx"
    args: ["-y", "restack-ai", "mcp"]
    env:
      ANTHROPIC_API_KEY: "${env:ANTHROPIC_API_KEY}"
    timeout: 900          # restack_convert runs long — default is 300s per call
    connect_timeout: 60
    Secrets: Hermes interpolates ${ENV_VAR} (and the Cursor-style ${env:ENV_VAR}) from the process environment or ~/.hermes/.env — so you never paste the key into the config itself. You can also hardcode the key, but the reference form is safer.
  3. Restart Hermes (or reconnect MCP servers) and check the MCP status surface: restack should appear with 4 registered tools.
  4. Verify — ask: “Run restack_scan on ./legacy-app and show me the detected stack and token estimate.”
Safety tip: Hermes supports trust: untrusted per server — every write-capable tool call then requires your approval before it runs. Our tools do not declare read-only hints, so under untrusted all restack calls ask first (safest); if that is too noisy, keep the default and gate restack_convert with a tools: filter until you need it: 
    tools:
      include: [restack_scan, restack_plan, restack_status]

Driving the pipeline from the agent

The recommended conversation pattern keeps the expensive step behind a checkpoint:

  1. “restack_scan ./legacy-app — what stack is this and what will it cost?”
  2. “restack_plan ./legacy-app with target nextjs. Show me the summary, decisions and risks.” — read the plan; adjust with --target/globs if needed.
  3. “The plan looks good — restack_convert with maxCostUsd 10 and outDir ./converted.” — the cost guard aborts before a call that would exceed the budget.
  4. Interrupted? Resume by asking again with resume: true — already-converted sources are skipped, or check progress any time with “restack_status for ./converted.”

Troubleshooting

SymptomFix
Server not listed / 0 tools Check node -v ≥ 20; the very first npx run needs network access. Restart the host so it re-launches the server.
No model provider key found The key env var is not reaching the server process — set it in the config's env block (Antigravity) or ~/.hermes/.env (Hermes).
Tool call times out during restack_convert Conversions are long. Raise the tool timeout (Hermes: timeout: 900+) or run the conversion from the CLI with --json and let the agent poll restack_status instead.
Windows: server fails to start with "command": "restack" Use the npx form: "command": "npx", "args": ["-y", "restack-ai", "mcp"].
Where did the output go? The converted project is in <outDir> (default ./converted); state and plan live under <outDir>/.restack/. Ask the agent for restack_status any time.
Other MCP hosts (Claude Code, Cursor, Windsurf, ...) use the same mcpServers JSON shape as Antigravity — see the README example and the CLI Reference → restack mcp for the full tool/argument tables.
