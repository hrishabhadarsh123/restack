Legacy code in. Modern stack out.

restack reads an old PHP/jQuery or Python 2 project in one 200k-token planning call, then converts it file-by-file into an idiomatic Next.js + TypeScript or FastAPI codebase. Originals are never touched.

CI MIT Node ≥ 20 Issues

Three commands

1

scan

Detect the stack (PHP/jQuery vs Python 2), inventory files, estimate tokens and cost. No API key needed.

2

plan

One big Claude call over the packed project produces a structured migration plan: mappings, routes, waves, risks.

3

convert

Waves of batches with verify + repair loops (tsc / ast.parse), checkpoint/resume, and a hard cost guard.

Quickstart

git clone https://github.com/hrishabhadarsh123/restack.git
cd restack && npm install && npm run build

export ANTHROPIC_API_KEY=sk-ant-...

# dry analysis — no key needed
node dist/cli.js scan ./legacy-app

# plan + convert
node dist/cli.js convert ./legacy-app --target nextjs --out ./converted
--target is optional — restack picks it from the detected stack (php-jquery → nextjs, python2 → fastapi). A --max-cost guard (default $20) aborts before overspending, and an interrupted run resumes with --resume.

How the 200k window is used

Scanstack + inventory + tokens
→
Packverbatim first, head+tail for big files
→
Planone call → plan.json
→
Convertwaves · ≤3 files/batch · verify
→
Reviewoptional consistency pass

The planning prompt carries an inventory of every file plus verbatim source for as many as fit (entry/config/routes first). Conversion batches reuse the plan via prompt caching, so the stable context is billed at cache-read prices.

Safety by default

Secrets never packed

.env, key files and credentials are detected and excluded from model context before any API call.

Originals untouched

All output goes to a separate --out directory; the legacy project is only ever read.

Cost guard

--max-cost aborts before a call that would exceed the budget; 429/5xx get exponential backoff.
