CLI Reference

Every command, flag and default — as wired in src/cli.ts.

Global

restack [options] [command]
OptionDescription
-V, --versionPrint the restack version
-h, --helpHelp for any command (restack <command> --help)

If --target is omitted on plan/convert, it is picked from the detected stack: php-jquery → nextjs, python2 → fastapi, django → fastapi. Undetectable stacks require an explicit --target.

restack scan

restack scan <projectRoot>

Detect the legacy stack, inventory files, estimate tokens and planning cost. No API key needed.

FlagDescriptionDefault
--include <glob...>Only include files matching these globsall source files
--exclude <glob...>Exclude files matching these globs—
--jsonMachine-readable JSON report on stdout (logs stay on stderr) — stack, confidence, per-file roles/tokens, excluded sensitive filesoff
--verboseDebug loggingoff

Sensitive files (.env, keys, credentials) are always discovered and excluded from readable content — they show up as warnings, never in prompts. 

restack scan ./legacy-app --json | jq '{stack, confidence, totalTokens}'

With --json the report goes to stdout and human-readable log lines stay on stderr, so restack scan app --json 2>/dev/null is always valid JSON — handy for scripts and CI checks. File contents are never included in the report.

restack convert

restack convert <projectRoot> [--target nextjs|fastapi] [--out dir]

Full pipeline: plan → batched conversion with verify/repair → optional review.

FlagDescriptionDefault
--target <t>nextjs | fastapiauto-detected
--out <dir>Output directory for the converted project./converted
--provider <id>anthropic | openai | googleauto-detected from env
--model <id>Model id (any provider)provider default

--jsonStream newline-delimited JSON events (run, wave, batch_start, batch_complete, file, warning, summary) on stdout, each tagged with schema; logs stay on stderr. Mutually exclusive with --interactive when it ships.off
--resumeReuse the saved plan and skip sources already converted in .restack/state.jsonoff

--include <glob...>Only include files matching these globsall source files
--exclude <glob...>Exclude files matching these globs—

Globs support **, *, ? and {a,b} alternation — e.g. --exclude "**/*.min.js" "**/legacy/**".

restack mcp

restack mcp

Run the restack MCP server on stdio so agent platforms (Google Antigravity, Hermes Agent, Claude Code, Cursor, ...) can drive the pipeline as tools. Step-by-step connection guides: Agent Setup. No flags besides --verbose — the server is configured by the environment (provider keys) of the host process.

ToolArgumentsNotes
restack_scan projectRoot, optional includeGlobs/excludeGlobs No API key needed
restack_plan projectRoot, optional target, provider, model, maxCostUsd Dry run — saves .restack/plan.json
restack_convert projectRoot, optional outDir, target, provider, model, workers, maxCostUsd, resume, review Full conversion with verify/repair + checkpointing
restack_status optional outDir Previous-run statuses, spend, what would resume

Each result carries an agent-facing summary plus a machine-readable _restack JSON block (schema-versioned where the CLI supports --json), so agents can chain scan → plan → convert → status and react to real data. Human logs stay on stderr; the MCP stdio transport owns stdout. 

{
  "mcpServers": {
    "restack": {
      "command": "npx",
      "args": ["-y", "restack-ai", "mcp"],
      "env": { "ANTHROPIC_API_KEY": "sk-ant-..." }
    }
  }
}

Exit behavior

Commands exit 0 on success (including a finished conversion with some failed batches — check the summary and .restack/state.json) and 1 on errors: missing API key, planner failure, or a CostLimitError from the --max-cost guard (spend so far is reported).
